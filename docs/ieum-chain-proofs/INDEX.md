## 검증 방법

1. `proofs/<파일>.txt` 의 SHA-256(파일 전체)을 `.ots` 와 함께 https://opentimestamps.org 에 올리면 비트코인 블록과 시각이 확인됩니다. (`.ots` 는 txt 파일 자체의 해시를 도장 찍은 것입니다.)
2. `soul_sha256` 은 해당 커밋 시점의 SOUL.md(LF 줄바꿈 바이트)의 지문입니다. SOUL 본문을 공개하지 않으므로 제3자가 직접 재계산할 수는 없고, 이음의 SOUL 원문과 대조하는 것은 작성자만 할 수 있습니다.

## 줄바꿈 차이 (장부와의 관계)

- 이음 장부 테스트넷의 v1–v4 해시는 history/SOUL_v*.md(Windows 줄바꿈 CRLF) 파일의 해시이고, 이 표의 soul_sha256은 같은 내용을 LF 줄바꿈으로 계산한 것이라 값이 다릅니다. 그래서 이 표에 남은 기록의 LF 해시를 장부에 새 버전으로 추가해 두었습니다(트랜잭션은 장부 README 참고).

## 같이 있는 파일

- `proofs/*.txt`, `proofs/*.ots` — 원본에서 복사. `.ots` 는 복사본에서만 비트코인 확정분을 병합(upgrade)했습니다(원본 폴더는 그대로).
- `.ots` 는 해당 txt 파일의 해시를 도장 찍은 것이라, txt를 고쳐 쓰면 증명이 깨집니다.
